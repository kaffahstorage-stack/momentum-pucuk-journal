Hubungkan MT5

Belum terhubung
Jalankan start_journal.bat dan buka MT5 terlebih dahulu.
Cara menghubungkan
  1. Download ZIP repository, ekstrak di PC Windows.
  2. Pasang Python 3.11 atau 3.12 versi 64-bit. Buka MT5 dan login seperti biasa.
  3. Klik dua kali start_journal.bat. Salin kode penghubung yang muncul ke kolom di atas.
  4. Jika browser meminta akses jaringan lokal, izinkan untuk website ini. Jika koneksi GitHub diblokir browser, buka versi lokal yang sama.
  5. Biarkan MT5 dan penghubung tetap berjalan. Tidak perlu password broker di website.
Untuk tes TP pucuk, gunakan komentar PUCUK atau magic number khusus pada order. Tanpa penanda ini, website tidak dapat memastikan bahwa trade berasal dari indikator TP pucuk. Riwayat lama tetap ditampilkan sesuai filter.
